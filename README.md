# 🤖 AI Chatbot using Streamlit

## 📌 Project Description
This project is an AI-based chatbot built using Python and Streamlit.  
It answers user queries related to CodeAlpha internship tasks using similarity matching.

## 🚀 Features
- Interactive chatbot UI
- Fast response system
- Handles unknown questions
- Built using Streamlit

## 🛠️ Technologies Used
- Python
- Streamlit
- NLP (basic similarity logic)

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
